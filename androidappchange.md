# 📚 StudyVault

**Tagline:** Scan. Organize. Study.

An offline-first student productivity app that combines a document scanner, PDF manager, study planner, and revision tools into one clean experience.

---

# 🎯 Goal

Instead of using multiple apps for scanning documents, reading PDFs, organizing notes, and tracking studies, StudyVault provides everything in one place.

---

# ✨ Core Features

## 📄 Smart Document Scanner
- Auto edge detection
- Perspective correction
- Auto crop
- Color / Black & White / Grayscale filters
- Batch scanning
- Merge multiple pages
- Save as PDF
- Save as Image
